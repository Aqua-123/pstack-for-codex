# How

Delegation and optional capabilities follow `../poteto-mode/references/codex-agent-runtime.md`.

Explore the codebase to answer "how does X work?" questions.

If the scope is ambiguous, state your interpretation and explore. The user can redirect.

## 1. Explain

Spawn one read-only agent that explores and explains in one pass. Use a validated configured profile when one is observable; otherwise use a generic agent with the inherited model pair. If no agent is available, do the same work sequentially in the parent. Give it the user's question and this brief:

> You are writing an architectural explanation for a senior engineer. Explore the codebase and write an explanation that a senior engineer unfamiliar with this area could read and walk away with a solid mental model. They should understand the architecture well enough to start working in it confidently. You have read-only access to the codebase.

## 2. Present

Present the agent's output. Light edits for clarity or context from the conversation are fine. Do not substantially rewrite it.
